# Python Login System

A beginner Python project that simulates a basic user registration and login process using terminal input and conditional logic.

## Features
- Username and password registration
- User credential verification
- Repeated login attempts when credentials are incorrect
- Success and error messages

## Concepts Practised
- Variables and user input
- Conditional statements (`if`, `else`)
- Logical operators (`and`, `or`)
- `while` loops
- String comparison

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run `python main.py`.

## Limitations
This project is intended for educational purposes only. Credentials are stored in plain text in memory, and the program does not implement secure authentication or persistent user accounts.
